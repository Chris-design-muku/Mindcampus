# MindCampus

A polished responsive website prototype for MindCampus — a student wellbeing ecosystem for high-pressure campuses.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — interactions, modals, check-in, service selection and demo forms

## Run locally
Open `index.html` in a browser.

## Deploy
Upload all three files to a GitHub repository and import that repository into Vercel.

## Important
This is a front-end prototype. Login, counselling booking, anonymous support, database storage, notifications and real therapist connectivity are represented as demo interactions and are not production medical/clinical services.
